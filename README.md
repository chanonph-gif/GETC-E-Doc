# GETC E-Doc

ระบบสารบรรณและติดตามงานสำหรับกองเสมือน ใช้รับเรื่อง มอบหมาย ติดตามหนังสือส่ง และค้นเอกสารย้อนหลัง โดยเชื่อมอ้างอิงกับระบบสารบรรณเดิมขององค์กร

**สถานะโครงการ:** เตรียมข้อกำหนดและรายการงานแล้ว ต้นแบบหน้าจอและระบบใช้งานจริงยังไม่เริ่มพัฒนา

## เริ่มทำงาน

1. อ่าน [แผนพัฒนา](docs/development-plan.md) และ [ข้อกำหนดกับประเด็นที่ต้องกำหนด](docs/decisions.md)
2. เริ่ม [รอบ 0](docs/round-0.md) เพื่อกำหนดแบบฟอร์ม บทบาท เลขทะเบียน และทดลองเดินเรื่อง
3. ใช้ [รายการงาน ED-01 ถึง ED-22](docs/backlog.md) คู่กับ [Issues](https://github.com/chanonph-gif/GETC-E-Doc/issues) ติดตามการพัฒนา
4. ใช้ [เกณฑ์ตรวจรับ U01 ถึง U14](docs/acceptance.md) เป็นฐานตรวจผลก่อนเปิดนำร่อง

## ขอบเขตรุ่นแรก

- ทะเบียนรับและส่ง พร้อมเลขติดตามภายในกอง
- แฟ้มเรื่อง เจ้าของเรื่อง งานย่อย การส่งตรวจ และติดตามกำหนด
- ไฟล์เอกสารหลายรุ่น ฉบับส่งจริง และหลักฐานการส่งรายผู้รับ
- ค้นข้อมูลทะเบียน ภาพรวมงานค้าง และส่งออกตามสิทธิ์
- บทบาท สิทธิ์รายเรื่อง ประวัติเหตุการณ์ การสำรองและกู้คืน

เลขหนังสือทางการและการลงนามใช้กระบวนการองค์กรในช่วงแรก เก็บเลขอ้างอิงกลับไปยังระบบเดิม การเชื่อมอัตโนมัติและการออกเลขทางการในระบบใหม่นำมาพิจารณาหลังยืนยันวิธีเชื่อมกับอำนาจของกอง

## สภาพแวดล้อมและข้อมูล

ยังไม่ได้เลือก framework ฐานข้อมูลผู้ให้บริการ หรือพื้นที่ติดตั้ง ระยะเวลา งบประมาณ และความสามารถเชื่อมระบบเดิมเป็น **Data unavailable** ให้กำหนดจากทีมพัฒนาและข้อกำหนดองค์กรในรอบ 0

Repository นี้เป็น public ใช้เฉพาะข้อกำหนดและข้อมูลสมมติสำหรับการพัฒนา เก็บหนังสือจริง ข้อมูลบุคลากร บัญชีเข้าใช้ และความลับของระบบในพื้นที่ที่องค์กรกำหนด ไฟล์ `.gitignore` ช่วยลดการเพิ่มไฟล์เหล่านี้โดยไม่ตั้งใจ แต่ยังต้องตรวจไฟล์ก่อน commit ทุกครั้ง
