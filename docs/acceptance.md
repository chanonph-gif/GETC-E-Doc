# เกณฑ์ตรวจรับรุ่นแรก

สถานะของ U01 ถึง U14 คือ **ยังไม่ทดสอบ** ตารางนี้เป็นผลที่คาดหวังสำหรับระบบที่จะพัฒนา เก็บผลจริงและหลักฐานใน Issue ของงานที่เกี่ยวข้อง

## กรณีตรวจรับ

| กรณี | ผลที่ต้องตรวจพบ |
| --- | --- |
| U01 รับจนตอบจบ | รับหนังสือ มอบหมาย ตรวจ บันทึกส่ง และปิดเรื่อง ค้นเอกสารกับประวัติครบ |
| U02 เพื่อทราบ | รับทราบเป็นรายคน ไม่มีงานตอบกลับถูกสร้างโดยไม่จำเป็น |
| U03 หลายผู้ปฏิบัติ | เจ้าของรวบรวมหลายงานได้ งานย่อยเสร็จหนึ่งงานไม่ปิดทั้งเรื่อง |
| U04 เรื่องที่กองเริ่มเอง | เปิดเรื่องและร่างหนังสือส่งได้โดยไม่มีหนังสือรับ |
| U05 ส่งกลับและเปลี่ยนรุ่น | เก็บคำตรวจและรุ่นเดิม ฉบับแก้หลังผ่านตรวจต้องตรวจใหม่ |
| U06 เลขพร้อมกันและกดซ้ำ | คำขอพร้อมกันไม่ออกเลขซ้ำ คำขอเดิมที่ส่งซ้ำไม่สร้างทะเบียนเพิ่ม |
| U07 ปีและการยกเลิก | ทดสอบก่อนและหลังจุดตัดปี รวมย้อนหลังและยกเลิก เลขเดิมยังตามได้ |
| U08 สิทธิ์ทุกช่องทาง | ผู้ไม่มีสิทธิ์เข้าหน้า API ไฟล์ ลิงก์ตรง รายงาน และผลค้นหาไม่ได้ |
| U09 เปลี่ยนคนและผู้แทน | โอนงาน ยุติสมาชิก และหมดช่วงรักษาการแล้วสิทธิ์เป็นไปตามกำหนด |
| U10 ส่งผิดหรือส่งล้มเหลว | เก็บผลรายผู้รับ ส่งใหม่ได้โดยคงหลักฐานและเลขทะเบียนเดิม |
| U11 ปิดและเปิดเรื่อง | เรื่องค้างงานจำเป็นปิดไม่ได้ เปิดใหม่พร้อมเหตุผลโดยประวัติไม่หาย |
| U12 ตัวเลขและส่งออก | ตัวนับตรงรายการ ข้อมูลส่งออกอยู่ในสิทธิ์ และเปิดอ่านอักษรไทยได้ |
| U13 ไฟล์และการกู้คืน | ปฏิเสธไฟล์ที่ไม่ผ่านข้อกำหนด กู้ทะเบียน ไฟล์ และประวัติแล้วเชื่อมกันได้ |
| U14 การใช้งานจริง | ใช้ภาษาไทยและมือถือได้ คีย์บอร์ดทำงานสำคัญได้ บันทึกไม่สำเร็จแล้วข้อมูลไม่หาย |

## วิธีเก็บผลตรวจ

แต่ละกรณีให้บันทึกเวอร์ชันหรือ commit สภาพแวดล้อม ผู้ตรวจ วันที่ บทบาทผู้ทดสอบ ข้อมูลสมมติที่ใช้ ขั้นตอน ผลจริง และหลักฐาน ใช้ผู้ใช้แยกบทบาท ทดสอบคำขอพร้อมกันกับคำขอซ้ำ และตรวจทั้งหน้าจอ API และไฟล์ตามกรณี

## เงื่อนไขก่อนเปิดนำร่อง

- กรณีสิทธิ์ เลขทะเบียน ข้อมูลสูญหาย และการกู้คืนต้องผ่านทั้งหมด
- แก้ปัญหาที่ทำให้รับหรือส่งเรื่องหลักไม่ได้ก่อนเปิดใช้
- รายการค้างอื่นต้องระบุผลกระทบ ผู้รับผิดชอบ กำหนดแก้ และผู้รับรองผล
- กำหนดและวัดเวลาตอบสนอง ผู้ใช้พร้อมกัน ขนาดไฟล์ ระยะข้อมูลสูญหายที่ยอมรับได้ และเวลากู้คืนจากขนาดใช้งานที่ตกลง
- มีวิธีรับเรื่องชั่วคราวเมื่อระบบขัดข้องและวิธีกระทบยอดทะเบียนกลับ โดยไม่ออกชุดเลขแข่งขันกันหลายช่องทาง
