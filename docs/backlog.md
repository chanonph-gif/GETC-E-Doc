# รายการงานพัฒนา

## การปิดงาน

ทำเครื่องหมาย ED ว่าเสร็จเมื่อผ่านเกณฑ์ของรายการนั้นและแนบหลักฐานแล้ว หากมีส่วนที่ยังค้างให้แยกงานและระบุผลกระทบ การเปิดนำร่องต้องผ่านเงื่อนไขใน [เกณฑ์ตรวจรับ](acceptance.md)
