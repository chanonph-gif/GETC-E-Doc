# ผลตรวจต้นแบบรอบ 0

วันที่ 29 ตุลาคม 2569 ตรวจต้นแบบใน prototype/ ด้วยข้อมูลสมมติ ผลนี้ใช้ประกอบ ED-01 และ ED-02 ส่วนเกณฑ์ตรวจรับระบบจริง U01 ถึง U14 ยังคงสถานะยังไม่ทดสอบ

## ผลตรวจด้วยคำสั่ง

| คำสั่ง | ผล |
| --- | --- |
| npm run check | ผ่านการตรวจ syntax ของไฟล์แอปและสคริปต์ |
| npm test | ผ่าน 25 กรณี ครอบคลุมแบบคำสั่ง ข้อมูลจำลอง และ static server |
| npm run build | สร้างไฟล์เว็บใน dist/ ได้ |

ชุดทดสอบตรวจการแยกสิทธิ์จำลองจากผลค้นหาและส่งออก การรับรายการซ้ำ การรับร่าง การแยกเลขตัวอย่างตามปี การแยกผู้ส่งกับผู้ตรวจ การส่งกลับพร้อมเหตุผล รุ่นเอกสาร การรับทราบ เกณฑ์ปิดเรื่อง การโอนงาน สมาชิกที่สิ้นสุด และการส่งออก CSV รวมถึงไม่เปิดไฟล์ repository ผ่าน static server

## ผลตรวจบน Chrome

| ขั้นตอน | ผลที่ตรวจพบ |
| --- | --- |
| ตัวนับรอคัดแยกและมอบหมาย | กดตัวนับ 2 แล้วเห็นร่างกับเรื่องรอมอบหมายรวม 2 รายการ |
| รับหนังสือใหม่ | กรอกต้นทาง เลข และเอกสารที่รอติดตาม ได้เลขตัวอย่าง DEMO-IN-2569-0009 และเปิดหน้ารายละเอียดได้ |
| มอบหมายและเพิ่มงาน | เลือกอรินเป็นเจ้าของ กำหนดส่งภายในต่างจากกำหนดตอบ และเพิ่มงานตรวจให้ธนาได้ |
| รับงาน ส่งตรวจ และแก้ไข | ผู้ปฏิบัติรับงาน ส่งรุ่น 1 ผู้ตรวจส่งกลับพร้อมคำแนะนำ แล้วส่งรุ่น 2 ได้ |
| แนบไฟล์และโหลดใหม่ | แนบ TXT สมมติในผลงานรุ่น 2 โหลดหน้าใหม่แล้วยังเปิดอ่านข้อความเดิมจากไฟล์ได้ |
| ตอบกลับและปิดเรื่อง | ผ่านการตรวจ บันทึกการตอบกลับตัวอย่าง ระบุผลดำเนินงาน และปิดเรื่องได้ ประวัติแสดงทุกขั้นพร้อมผู้ทำ |
| รับทราบ | มุมมองศิริรับทราบแล้ว รายการรอรับทราบลดจาก 1 เป็น 0 |
| กองเริ่มเรื่องเองและเปลี่ยนคน | เปิดเรื่องโดยไม่มีหนังสือรับ เปลี่ยนเจ้าของเป็นภูมิพร้อมเหตุผล และเห็นประวัติเดิม |
| ค้นและส่งออก | ค้นจากเลขต้นทางแล้วได้ 1 รายการ กดส่งออก CSV ได้ตามผลค้นหา |
| รูปแบบมือถือ | ตรวจใน iframe กว้าง 390 พิกเซล เนื้อหาไม่ล้นแนวนอน เมนูเปิดได้ และแบบรับหนังสือเรียงช่องเป็นหนึ่งคอลัมน์ |

การตรวจมือถือเป็นการตรวจ responsive layout ใน browser ไม่ใช่การทดสอบบนอุปกรณ์จริง ฟอนต์ไทยเก็บในชุดเว็บและไม่ได้เรียกบริการฟอนต์ภายนอก

## ขอบเขตผลตรวจ

ผลทั้งหมดเป็นต้นแบบที่เก็บข้อมูลใน browser การยืนยันตัวตน สิทธิ์ฝั่งเซิร์ฟเวอร์ ธุรกรรมฐานข้อมูล การออกเลขหลายผู้ใช้ การตรวจไฟล์ใช้งานจริง การสำรองกู้คืน และการเชื่อมระบบองค์กรยังไม่ได้พัฒนา ข้อกำหนดดังกล่าวต้องตรวจอีกครั้งในรอบพัฒนาระบบจริง

แบบฟอร์ม รายการบทบาท อายุเก็บ รอบปี และพื้นที่ติดตั้งยังต้องให้ผู้รับผิดชอบองค์กรกำหนดก่อนปิด ED-01 และ ED-02
